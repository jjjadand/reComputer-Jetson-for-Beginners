## 建议学习顺序

1. 先完成 `5.1`，确保 `Ollama`、`Open WebUI` 和基础运行环境可用。
2. 再阅读 `5.2` 与 `5.3`，分别建立文字大模型和视觉多模态模型的使用认知。
3. 最后结合 `5.4` 和 `5.5`，将语音输入、语音输出与多模态能力串联起来。
